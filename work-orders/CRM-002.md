## Outcome

A containerised extractor, `crm-migrate`, that:
- reads Salesforce **only**;
- selects fields explicitly from a versioned source-field contract;
- writes a consistent, checksummed snapshot into a restricted runtime directory;
- produces a counts-only reconciliation report covering record counts, relationship integrity, fill rates, deletions and drift.

It is built and proven entirely against a **fake Salesforce API with synthetic fixtures**. This WO grants **no Salesforce access** and extracts **no customer record**. The live steps (§ Live stages) are each separately authorised by the Product Owner.

2. **Extractor package: `migrate/crm_migrate/`.** Python 3.13 **standard library only**. It has four modes:
   - **`contract-check`** reads `describe` metadata only, with no records. It verifies that every contract field exists and is readable. It records each object's `createable`, `updateable` and `deletable` flags as seen by the integration user, and **fails if any object is createable, updateable or deletable**. This is the read-only evidence.
   - **`count`** runs `SELECT COUNT()` per object, which returns no records.
   - **`extract`** takes the full snapshot:
     - it records the snapshot time `T0` from the server;
     - it queries each object with `SystemModstamp <= T0` through `queryAll`, so `IsDeleted` rows within the recycle-bin window are captured and flagged;
     - it pages with `nextRecordsUrl`;
     - it writes one gzip JSONL file per object plus a `manifest.json`. The manifest holds T0, the API version, the exact SOQL, the contract version and sha256, the per-object counts and durations, and a sha256 per file.
     - All files are mode `0600` in a new snapshot directory. An existing directory is never overwritten.
   - **`reconcile`** reads a snapshot and writes `reconciliation.json` plus a Markdown summary, both **counts only**:
     - the extracted count against `count` mode for each object;
     - duplicate ids;
     - relationship integrity, with orphans counted per relation:
       - `Account.ParentId` → Account;
       - `Contact.AccountId` → Account;
       - `Opportunity.AccountId` → Account and `Opportunity.OwnerId` → User;
       - `OpportunityContactRole` → Opportunity and Contact;
       - Task and Event `WhatId`, `WhoId` and `AccountId` resolved by key prefix;
       - `OwnerId` → User for every object;
       - `EmailMessage.ActivityId` → Task;
       - `EmailMessageRelation.EmailMessageId` → EmailMessage, and `RelationId` → Contact or User;
     - fill rate per contract field;
     - **deletions**: ids present in the previous snapshot but absent now, plus `IsDeleted=true` rows;
     - **drift**: a `COUNT()` of rows with `SystemModstamp > T0`, taken after the extraction.
3. **Read-only by design, in code.**
   - All HTTP goes through one client that permits **only**:
     - `POST` to the OAuth token endpoint (`/services/oauth2/token`);
     - `GET` to `/services/data/vNN.N/` under `query`, `queryAll`, `sobjects/<Object>/describe`, `limits`, and the `nextRecordsUrl` paths those return.
   - Any other method or path raises before a socket is opened. There is no code path that composes a write, and no SOAP.
   - **Authentication is OAuth 2.0 client credentials** (Connected App, run-as a dedicated read-only integration user). No username/password flow, because the SOAP `login()` retirement is due in summer 2027.
   - The instance URL must be `https://*.my.salesforce.com`. It, the client id and the client secret come from the runtime env file only.
4. **Container: `deploy/migrate/compose.json`.**
   - Project `crm-migrate`, a one-off service `crm-migrate`.
   - Image `python:3.13.9-slim-trixie@sha256:326df678c20c78d465db501563f3492d17c42a4afe33a1f2bf5406a1d56b0e86`, unmodified. No image is built.
   - `migrate/` is mounted **read-only** and run as `python -I -m crm_migrate <mode>`.
   - Hardening:
     - non-root `user`, `read_only: true` root filesystem, `cap_drop: [ALL]`, `security_opt: [no-new-privileges:true]`;
     - `tmpfs` `/tmp`;
     - **no `ports`**, no external networks or volumes;
     - the only writable bind is the snapshot directory, under `/srv/CRM/runtime/migrate/snapshots/`;
     - secrets come from `/srv/CRM/runtime/migrate/env` (root, `0600`).
   - Add `deploy/migrate/env.example`, with names only.
   - Add `scripts/migrate.sh`. It refuses unless the target is `migrate` and the runtime directory is `/srv/CRM/runtime/migrate`, which is root-owned and `0700`. It refuses any secret exported in the shell, and runs Compose with every env-file name removed from its environment, as CRM-001-C2 and the LAN change do.

## Acceptance criteria

**In the loop** (synthetic fixtures, no network):
1. **AC1:** unit tests pass with exact counts reported, and every policy rule fails against its broken fixture.
2. **AC2:** generated SOQL equals the contract exactly. A field outside the contract, a wildcard or `FIELDS(ALL)` is refused.
3. **AC3:** the HTTP client refuses every method or path outside the permitted list (`POST`/`PATCH`/`PUT`/`DELETE` to data URLs, composite, sObject collections, Bulk API, SOAP and Apex REST) **before** connecting. The fake server records zero write requests across the whole suite.
4. **AC4:** `contract-check` fails when the fake reports any object as createable, updateable or deletable, or a contract field as missing or unreadable.
5. **AC5:** extraction against the fake returns the fixture's exact per-object counts across several pages. The manifest checksums verify, and a second run into a new directory gives identical record content.
6. **AC6:** deleted rows, ids missing from the previous snapshot, and rows modified after T0 are each reported with the planted counts.
7. **AC7:** reconciliation reports exactly the planted orphans, duplicates and fill rates for every relation listed in Change item 2.
8. **AC8:** no fixture content (the sentinel) appears in any stdout, stderr or log line in any mode, including on errors.
9. **AC9:** `deploy/migrate/compose.json` policy:
   - pinned digest equal to the register;
   - no ports;
   - read-only root filesystem, `cap_drop: ALL`, `no-new-privileges`, non-root;
   - `crm-` names, no `container_name`, nothing external;
   - only the snapshot directory writable.
10. **AC10:** `migrate.sh` refuses: a wrong target or runtime; a runtime not root-owned `0700`; an exported secret; and an existing snapshot directory.

**Expected loop outcome:** DELIVERED (`BROWSER: no`).
